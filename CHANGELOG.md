# Changelog

## 0.2.0 — 2026-10-23

- Portuguese (Brazil) menu translation added
- Language selector now supports English / Japanese / Português

## 0.1.0 — 2026-10-21

First release.

- Player ESP: boxes in solid, corner or rounded style, skeleton, name,
  distance, health and stamina bars
- Snapline, head marker and center crosshair, each togglable
- Automatic target selection (counselor tracks Jason, Jason tracks the
  counselors)
- Targets tab with a live table (name, distance, health, visibility)
- English/Japanese menu, switchable at runtime and persisted in the
  config file
- Config file persistence and hotkeys (INSERT menu, END ESP, DELETE
  quit)
- Read-only memory access: no writes, no injection, no driver
